資料關聯架構 / 說明

✅以下為 IFRS 問卷模組的資料層級關聯，供開發參考。
【面向】環境面 / 社會面 / 治理面 ← 議題面向管理（現有）
└─ 【ESG 議題】氣候策略與能源管理、水資源管理… ← ESG 議題清單（現有，加 SASB 欄）
└─ 1對多 ↓

    └─ 【永續主題】氣候策略 / 能源管理… ← 永續主題管理（新頁面，掛在議題下 1對多）
└─ 【風險／機會清單】掛在主題下 ← 風險/機會清單（新頁面，掛在主題下 1對多）
├─ 風險：碳定價上升、水資源短缺…
└─ 機會：節能產品、RE100…

【部門綁定】部門 A → 永續主題 X, Y ← P04 問卷發放設定

【填答介面】同仁登入 → 選部門 → 帶出永續主題 → 展開各主題的風險/機會清單
└─ Part 2：IRO 類型 / 時間尺度
└─ Part 3a：量化衝擊 ← 財務衝擊項目管理（量化類型）
└─ Part 3b：質化 7 題 ← 財務衝擊項目管理（質化類型）
└─ Part 4：價值鏈位置 ← 價值鏈位置（新頁面）

【衝擊尺度】發生機率 / 金額 / EBITDA ← 問卷填答尺度管理（現有）
【SASB 對應】議題 ↔ SASB 標準 ← ESG 議題清單（加欄）
